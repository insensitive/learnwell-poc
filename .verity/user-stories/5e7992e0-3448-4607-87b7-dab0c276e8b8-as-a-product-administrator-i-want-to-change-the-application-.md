## Description

As a product administrator or brand owner, I want the application name to be updated from “Learnwell” to “Kidswell” so that the product reflects the intended brand identity. The change should update the name wherever the application displays its product or brand name within the agreed scope. No functional behavior, user data, URLs, or unrelated content should be changed as part of this update.

## Acceptance Criteria

- [ ] Given the application is configured with the name “Learnwell”, When the name change is applied, Then the configured application name is “Kidswell”.
- [ ] Given a user views a location within the application that displays the product name, When the page or component loads, Then it displays “Kidswell” instead of “Learnwell” within the approved scope.
- [ ] Given the name update has been deployed, When a user navigates between the affected application screens, Then the displayed product name remains consistently “Kidswell”.
- [ ] Given the application name has been changed, When a user uses unaffected application functionality, Then that functionality continues to operate without changes to its behavior or data.
